# Exact versions of every direct dependency, for reproducible installs.
#
#   pip install -c constraints.txt -e ".[dev]"      # developer / CI
#   pip install --no-cache-dir -c constraints.txt . # Docker image
#
# Why not a hash-pinned lock: a hashed lock is only meaningful for the single
# platform and Python version it was generated on, and this project ships for
# Linux/CPython 3.12+. Pinning the direct set here keeps installs reproducible
# without pretending cross-platform hashes are verified. Refresh deliberately:
#
#   pip index versions <package>        # review the changelog first
#   sed -i 's/^<package>==.*/<package>==<new>/' constraints.txt
#   pip install -c constraints.txt -e ".[dev]" && pytest && python -m ishastra.lab
#
# `pip-audit` runs against the installed environment in CI, so a new advisory
# against anything in this set (or its transitive closure) fails the pipeline.
#
# Every package listed in pyproject.toml's runtime and dev extras belongs here;
# a dependency that is only pinned in pyproject.toml can drift between runs.
